# Spec Directory

This directory contains the architectural specification of the Enxame project.

The specification is the source of truth. Architecture is described by the specification. Code implements the specification.

## Structure

- `constitution/` - Project constitution and glossary
- `domain/` - Domain models and fundamental concepts
- `protocols/` - Protocol specifications
- `diagrams/` - Architecture diagrams
- `schemas/` - Validation schemas
- `eip/` - Enxame Improvement Proposals

## Priority

1. Read `ARCHITECT_RULES.md` first
2. Consult `ROADMAP.md` for planning
3. Reference `dependency_rules.md` for dependency rules
