# Diagrams

Diretório de diagramas arquiteturais do projeto Enxame.

## Diagramas Planejados

| Diagrama | Tipo | Status | Descrição |
|----------|------|--------|-----------|
| Contexto | C4 | Pendente | Visão geral do sistema e integrações |
| Container | C4 | Pendente | Containers principais e comunicações |
| Componente | C4 | Pendente | Componentes internos de cada container |
| Sequência | UML | Pendente | Fluxos de comunicação entre nodes |
| Estado | UML | Pendente | Máquinas de estado de entidades |
| Deploy | Infra | Pendente | Topologia de deployment |

## Formato

Diagramas serão armazenados em:
- **Mermaid** - Para diagramas versionáveis em texto
- **PlantUML** - Para diagramas complexos
- **PNG/SVG** - Para diagramas exportados (quando necessário)

## Convenções

- Usar cores consistentes para tipos de componentes
- Legenda obrigatória em diagramas complexos
- Versionar arquivos fonte (.mmd, .puml) junto com exports
- Manter diagramas atualizados com a implementação

## Ferramentas Recomendadas

- Mermaid Live Editor
- PlantUML Server
- Draw.io (para edições manuais)
