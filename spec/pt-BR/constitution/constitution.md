# Constituição do Projeto Enxame

## Propósito

O projeto Enxame é um sistema distribuído de agentes autônomos coordenados através de protocolos de consenso.

## Princípios Fundamentais

1. **Autonomia** - Cada node opera independentemente
2. **Coordenação** - Nodes colaboram via protocolos definidos
3. **Resiliência** - Sistema tolera falhas individuais
4. **Extensibilidade** - Novas capabilities podem ser adicionadas sem breaking changes

## Modelo Organizacional

- **Nodes** - Unidades computacionais autônomas
- **Capabilities** - Habilidades que nodes possuem
- **Roles** - Funções atribuídas a nodes baseadas em capabilities
- **Missions** - Objetivos de alto nível
- **Tasks** - Unidades atômicas de trabalho
- **Workflows** - Sequências coordenadas de tasks

## Governança

- Arquitetura definida por Arquiteto-Chefe
- Implementação executada por Engenheiro de Implementação
- Mudanças requerem EIP (Enxame Improvement Proposal)
