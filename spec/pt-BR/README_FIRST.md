# Spec Directory

Este diretório contém a especificação arquitetural do projeto Enxame.

A especificação é a fonte da verdade. A arquitetura é descrita pela especificação. O código implementa a especificação.

## Estrutura

- `constitution/` - Constituição e glossário do projeto
- `domain/` - Modelos de domínio e conceitos fundamentais
- `protocols/` - Especificação de protocolos
- `diagrams/` - Diagramas arquiteturais
- `schemas/` - Schemas de validação
- `eip/` - Enxame Improvement Proposals

## Prioridade

1. Leia `ARCHITECT_RULES.md` primeiro
2. Consulte `ROADMAP.md` para planejamento
3. Referencie `dependency_rules.md` para regras de dependência
