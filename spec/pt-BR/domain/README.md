# Domain Models

Diretório de modelos de domínio do projeto Enxame.

## Modelos

| Arquivo | Conceito |
|---------|----------|
| `node.md` | Unidade computacional autônoma |
| `capability.md` | Habilidade funcional executável |
| `role.md` | Função baseada em capabilities |
| `mission.md` | Objetivo de alto nível |
| `task.md` | Unidade atômica de trabalho |
| `workflow.md` | Orquestração de tasks |
| `provider.md` | Fornecedor de recursos/serviços |
| `knowledge_source.md` | Fonte de informação consultável |
| `consensus.md` | Mecanismo de acordo distribuído |
| `message.md` | Unidade de comunicação |

## Princípios

- Cada modelo é independente e auto-contido
- Relações entre modelos são explícitas
- Modelos não contêm detalhes de implementação
- Schemas validam instâncias dos modelos
