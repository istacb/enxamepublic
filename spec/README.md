# Enxame Specification

This directory contains the architectural specification of Enxame.

The specification is the authoritative source of truth for the project.

## Language Policy

- English (`en/`) is the canonical specification.
- Portuguese (`pt-BR/`) is the official translation.
- Every architectural change must first be applied to the English specification.
- Translations must preserve meaning exactly.

## Directory Structure

- constitution/ → Fundamental principles.
- domain/ → Domain model.
- protocols/ → Communication contracts.
- eip/ → Enxame Improvement Proposals.
- schemas/ → Data schemas.
- diagrams/ → Architecture diagrams.

## Rule

Code implements the specification.

The specification never follows the code.
